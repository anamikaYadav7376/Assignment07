# Library Book Manager

A simple React-based Library Book Manager that allows users to browse books, filter them by genre, view book details, and issue or return books.

## Features
- View all books
- Filter books by genre
- View book details
- Issue and return books
- View issued books
- Dashboard with book statistics

## Tech Stack
- React
- Vite
- React Router
- CSS
- Local JavaScript dataset

## Installation & Setup

```bash
npm install
npm run dev
```

## Routes
- `/` – Home
- `/books` – All books
- `/books/:id` – Book details
- `/issued` – Issued books
